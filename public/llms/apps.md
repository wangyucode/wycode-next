# 应用 - 王郁的小站

> 个人实验项目集合：https://wycode.cn/apps 。涵盖 AI 应用、Web 工具、开源项目、移动端与桌面应用。

## 主要项目

- 青衿AI：有记忆、会做梦的 AI 伴侣（已于 7 月 1 日停服下线）。
- ONI 产物计算器：计算《缺氧》游戏中建筑/动植物/相变产物平衡的小工具（Web + 小程序，源码 https://github.com/wangyucode/oni ，在线页见 https://wycode.cn/oni）。
- 跨平台剪切板：跨平台跨网络发送文字（在线页 https://wycode.cn/clipboard ，agent 文档 https://wycode.cn/llms/clipboard.md）。
- Dogger：Rust + React 的 Docker Web UI（https://github.com/wangyucode/dogger）。
- SQLite WebUI：Rust (Axum) + Solid.js 的轻量 SQLite 管理工具（https://github.com/wangyucode/rust-sqlite-webui）。
- Crane：Rust 编写的 .tar.gz 下载部署工具（https://github.com/wangyucode/crane）。
- sftp-upload-action：通过 SFTP 部署文件的 GitHub Action（本站即用它部署）。
- 历史项目（部分已下线/停止维护）：Websocket 聊天室、西安公共自行车、局域网五子棋、DOTA2 助手、养鱼小助手、宝宝圈相册、Wengine 游戏引擎。

## 页面内容

- 每个项目含简介截图、类型标签、技术栈标签、源码/访问链接与是否下线说明。
- 页头有总项目数 / 开源项目数 / 活跃项目数统计。
